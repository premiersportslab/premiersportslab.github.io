# Nona Basketball League Website

A static, multi-page website built from the supplied `nona-basketball-league.html` design and prepared for GitHub Pages.

## Pages
- `index.html` — Home
- `about.html` — About
- `divisions.html` — Age divisions
- `schedule.html` — Schedule
- `register.html` — Pricing and registration
- `gallery.html` — League gallery
- `faq.html` — Frequently asked questions
- `contact.html` — Contact
- `404.html` — Custom error page

## First file to edit
Open `assets/js/config.js` and replace all `REPLACE_WITH_...` values.

## Local preview
Double-clicking `index.html` works for basic viewing. For accurate testing, use VS Code with Live Server or run:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.
